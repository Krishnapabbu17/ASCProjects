PERSONAL WEBSITE PRESENTATION NOTES

Goal: about 2 to 3 minutes. Do not memorize every word. Keep the website open and use each section as your reminder.

BEFORE RECORDING
- Open the public GitHub Pages link in a clean browser tab.
- Close notifications and unrelated tabs.
- Check that your camera and microphone are on.
- Keep this outline nearby, but look at the camera during the introduction and closing.

OPENING (camera + homepage)
Hi, my name is Krishna Pabbu, and this is my personal portfolio website. I built it with HTML, CSS, and JavaScript to introduce myself and highlight some of my research, data science, and programming projects.

HOMEPAGE
The homepage quickly explains who I am and what I am interested in. I used a clean blue design because it connects to technology and research while still being easy to read. I also included a few numbers that summarize my work, such as analyzing about 54,000 diamonds and reaching roughly 95 percent accuracy with my best classification model.

ABOUT SECTION
In the About section, I explain that I am a high school student interested in artificial intelligence, machine learning, data science, and natural language processing. I also included some of my leadership and personal interests so the website shows more than just my technical work.

PROJECTS SECTION
The Projects section is the main part of the website. It includes my autism language research, diamond cut classifier, What’s On My Ballot mobile app, and motor fault detection project.

[Click "Project details" on one card.]

Each card has a JavaScript button that reveals more information. Some projects also link directly to their GitHub repositories.

SKILLS SECTION
The Skills section groups the tools I have used into programming languages, data and machine learning, and software development. The page is also responsive, so the layout changes to fit phones and smaller screens.

INTERACTIONS
[Click the dark mode button.]

I used JavaScript to create dark mode and save the user's preference. I also used JavaScript for the project detail buttons and the current year in the footer.

CHALLENGE
One challenge was keeping the website organized and readable on different screen sizes. I solved that with CSS Grid, Flexbox, responsive media queries, and reusable color variables for both light and dark mode.

CLOSING (look at camera)
This project brings together what I learned about HTML, CSS, responsive design, and DOM interactions. I can continue updating it for future programs, research opportunities, internships, and college applications. Thank you for watching.

5. Show Skills.
6. Toggle dark mode.
